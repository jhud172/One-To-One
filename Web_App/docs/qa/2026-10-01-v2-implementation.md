The active goal is the complete page-by-page rebuild in the [audit](../audits/one-to-one-v2-design-workflow-usability-audit-2026-10-01.md). Implementation is underway; the stabilised baseline remains the starting point. This record separates implemented changes from visual acceptance and external release gates.

## Visual and interaction target

**Visual thesis:** Connected Performance combines a midnight navy workspace, clear cyan actions and a warm orange connection motif with a crisp, equally deliberate light theme.

**Content plan:** public pages introduce the coaching relationship, show a useful working example, explain verifiable standards and lead into role-specific joining; authenticated pages begin with today's work, then secondary context and history.

**Interaction thesis:** the entrance sculpture opens on deliberate activation; selection and disclosure use short consistent transitions; completion feedback follows actual saved state. Ordinary panels remain still. Reduced motion retains every action and readable state.
